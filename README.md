# Armstrong Waste Management — Frontend

Frontend-only prototype for Armstrong Global Solutions SMC Ltd.

## Preview
Open `index.html` in a modern web browser. No dependencies or build step are required for this initial GitHub version.

## Included
Responsive navigation, management dashboard, client directory, facility registration, service schedules, collections, payment demonstrations, staff summary, QR identity planning screen, schematic map, and reports.

## Important limitations
- All client/staff information is fictional demonstration data.
- Data is held in browser memory and resets on refresh.
- Payments are not processed or reconciled; demo payment status is not a financial ledger.
- No authenticated users, actual camera scanning, QR verification, GPS, geocoding, invoices, PDF receipts, or server database.
- The map is **schematic**, not actual facility coordinates.
- Never use the prototype as evidence of collection or receipt of money.

## Delivery policy
The requested delivery branch is `main`. Frontend-only changes are committed directly there. Backend work is deferred until approved.
